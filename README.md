# Laptop Bishkek

Где в Бишкеке поработать с ноутбуком: кафе, коворкинги и библиотеки со скоростью Wi-Fi, розетками, уровнем шума, ценой кофе и часами работы.

**Сайт:** https://sivatorx.github.io/laptop-bishkek/

- Фильтры: тихо, розетки, допоздна, рядом со мной.
- Кнопка «📶 Сообщить скорость Wi-Fi» на каждой карточке: посетители присылают свои замеры.
- Тёмная неоновая и светлая тема.

## Запуск на компьютере
```
npm start   # http://localhost:5173
npm test
```

Места хранятся в `data/places.js`.
